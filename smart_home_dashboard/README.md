# Smart Home Dashboard

A simple Smart Home Dashboard built using Flask, HTML, CSS and JavaScript.

## Features

- Light ON/OFF
- Fan ON/OFF
- AC ON/OFF
- Automation Schedule
- Scheduled Tasks
- Delete Schedule
- Responsive Design

## Installation

Open the terminal inside the project folder.

Run:

pip install -r requirements.txt

Then run:

python app.py

Open this address in your browser:

http://127.0.0.1:5000/

## Deployment

Build Command:

pip install -r requirements.txt

Start Command:

gunicorn app:app
